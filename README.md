# CRM AutoXpress

A comprehensive Customer Relationship Management system for automotive parts businesses, built with Rails, esbuild, and Tailwind CSS.

## Core Features

### Order Management
- Customer orders
- Order processing
- Status tracking

### Dispatching/Order Processing
- Payment processing
- Supplier management
- Fulfillment

### Callbacks
- Customer follow-up system

### Agent Management
- Performance tracking
- Role-based access

### Product Catalog
- Automotive parts inventory

### Refunds/Returns
- Return processing workflow

### Supplier Management
- Vendor relationships
- Pricing management

### Dashboard/Analytics
- Real-time metrics
- Reporting

## Real-Time Features

- Live order status updates
- Real-time agent performance metrics
- Instant callback notifications
- Live inventory updates
- Real-time dashboard charts
